# Footer sketch artwork

These original SVG drawings adapt the paper, seeded double-pencil strokes, hatching, black technical-name tape and restrained mechanical motion described by [sketchy](https://github.com/OthmanAdi/sketchy) and the local sketch-board skill. No JavaScript engine or sketch-catalog geometry was copied. No third-party logos are used.

The type is converted to SVG paths, so every SVG renders without installed fonts or network requests. Regenerate with `python generate.py` after installing `requirements.txt`.

- Caveat: Copyright 2014 The Caveat Project Authors, https://github.com/googlefonts/caveat. SIL Open Font License 1.1, full notice in `fonts/OFL-Caveat.txt`. The bundled variable font is instantiated at weight 600 for path conversion.
- Courier Prime: Copyright 2015 The Courier Prime Project Authors, https://github.com/quoteunquoteapps/CourierPrime. SIL Open Font License 1.1, full notice in `fonts/OFL-CourierPrime.txt`. The bundled bold face supplies the technical-name labels.

The original WOFF2 font files are preserved unchanged beside their licenses. They are generator inputs, not resources loaded by the SVGs. SVG text equivalents remain in title, description and labelled groups; the README provides linked text alternatives.

Animated files contain one small recurring gesture with a long rest interval and a reduced-motion media rule. The companion `-static-light.svg` and `-static-dark.svg` files contain no animation styles. Select those first in a picture element when the page prefers reduced motion; this also covers browsers that do not propagate the page's media preference into an SVG image document.
