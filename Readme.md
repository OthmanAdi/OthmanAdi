[**Planning with Files**](https://github.com/OthmanAdi/planning-with-files) · **28K+ GitHub stars**, checked 13 November 2026. I created this open-source skill for long-running coding agents and maintain its releases and outside contributions. It keeps `task_plan.md`, `findings.md` and `progress.md` on disk so an agent can pick up work after context loss, a crash or compaction. [Getting started](https://planningwithfiles.tech/) · [Recovery exercise](https://github.com/OthmanAdi/planning-with-files/tree/v3.28.1/examples/file-only-recovery).

[**zero-to**](https://github.com/OthmanAdi/zero-to) turns a researched study plan into an interactive 3D trail. Its skill checks sources; the roadmap gives learners practical tasks and checkpoints. [Walk an example](https://othmanadi.github.io/zero-to/gallery/).

## Professional work

At [migRaven](https://www.migraven.com) in Berlin, I work on agent infrastructure and graph-backed identity, data and access systems. I make architecture decisions and implement them, including the integrations and interfaces people need to use the result.

**[migRaven.MAX](https://max.migraven.com/): agent architecture and implementation.** I work on Rust orchestration, tool use, context management, and internal workflow and script-orchestration systems. The product connects Neo4j, enterprise connectors and LLM-assisted querying to identity, data and access management.

**[aikux.Brain](https://www.aikux.com/produkte/aikux-brain/): enterprise knowledge software.** My work includes agent orchestration, retrieval, product interfaces, integration, testing and release packaging. I also built its Windows installer. The product uses enterprise knowledge graphs and GraphRAG to make organizational knowledge accessible.

**[Archiver for Teams](https://www.migraven.com/webinar-migraven-archiver-fuer-teams/): integration through operation.** I built the Microsoft Graph integration and archive administration workflow, and handled tests, builds and operation. The end-to-end check was whether an administrator could find and open the archived files. The product also provides visibility into external permissions.

## Teaching and programmes

I've taught programming since 2020. My work has included developing curricula and learning applications, leading courses, reviewing code and helping learners turn projects into a professional portfolio. I was among the early mentors at Berlitz Digital School and StartSteps, and built curricula and learning software for those programmes and MindRefined.

- **Berlitz Digital School:** programming for children and young people. I led digital programming courses Monday through Saturday for more than three years.
- **StartSteps:** individual and group instruction in coding, web design, app development and cyber security, with live coding, code reviews, portfolio work and career coaching.
- **MindRefined:** networks, IT security and Linux for jobseekers, with interactive explanations and support adapted to the learners.
- **Morphos / ADZ:** technical curricula, projects and homework, learning applications and a classroom platform. I also prepare runnable examples, instructor guides and troubleshooting material for a co-instructor.

[Institutional references, dates and scope](./PROOF.md#institutional-references)

That work continues in software people can inspect. [Die Begriffsakte](https://github.com/OthmanAdi/laravel-ai-begriffsatlas) connects Laravel and Applied AI concepts through four depths of study, transfer questions and reflection. [Request-Labor](https://github.com/OthmanAdi/laravel-request-pipeline-warmup) asks learners to trace a request, predict HTTP responses and explain code. The newer [zero-to](https://github.com/OthmanAdi/zero-to) turns a study plan into a route with tasks and checkpoints.

I teach Python, agent-system design and production engineering practices. Developing and teaching these materials has shaped how I document systems, explain tradeoffs and work with people at different levels of technical experience.
